Quick start
  1. Choose an Excel or CSV workbook and select the worksheet.
  2. Confirm the detected columns in Column mapping, then select Apply mapping.
  3. Choose the production day and enter the shift settings.
  4. Set Jobs to plan, or enable Fill available shift.
  5. Select Run schedule.
  6. Review Data checks, then adjust the order with Schedule Positions or drag-and-drop.
  7. Print the finished schedule or download the arranged Excel file.

Important: Apply mapping confirms the spreadsheet layout. Run schedule is what creates or refreshes the schedule.

Workbook, worksheets, and job identity
  • EZDES accepts .xlsx, .xls, and .csv files.
  • It looks for a header row containing Copperweight and Speed. Column mapping handles different header names.
  • A job is identified by the first two WO segments. For example, 174-05-01 and 174-05-08 belong to job WO 174-05. TN is kept as a reference.
  • Jobs to plan counts WO groups, not individual spreadsheet lines. Every line belonging to a selected job stays with that job.
  • Use latest Excel file reads a server folder path and selects its newest Excel file. This folder feature requires the EZDES server; ordinary file upload works in the standalone HTML.
Column mapping and data checks
  • Copperweight and Speed are required. WO, TN, Number of cores, and Due date are optional but improve grouping and planning.
  • Apply mapping after loading a workbook. A saved preset can restore its mapping when those columns exist.
  • Data checks identify missing weights, missing speeds, invalid core counts, duplicate full work orders, and weights that have no timing rule.
  • A warning does not always prevent scheduling. An error such as a missing core-weight rule should be corrected before relying on the result.
Rule presets
  • A preset saves the current core-weight rules, production day, shift hours, start time, setup minutes, and column mapping in this browser.
  • Give the preset a name, choose Save preset, then use the list and Load later.
  • Loading a preset changes the settings but does not replace the source workbook. Select Run schedule to rebuild the result.
  • Delete removes only the selected preset from this browser.
Core-weight, speed, and job-time rules
  • Target speed is the expected running speed for that weight.
  • First core is the travel time before the first core reaches the end of the line.
  • Next core is the interval between each remaining core in the same line.
  • When a job follows the same effective weight, EZDES skips another first-core travel delay and uses the core interval.
  • h means half-ounce. A mixed value such as 2/h or 1/2 uses the heaviest component for target speed and timing.
  • Add core weight creates another editable rule. Adjust job-time settings hides or shows the full timing table.
  • Setup/changeover minutes are added at job boundaries. A mixed layer marked Bottom image can receive its specific changeover when it follows non-mixed copper.
Production-day priority and sorting
  • Monday favors lighter copperweights, Wednesday is balanced, and Friday favors heavier copperweights. Tuesday and Thursday transition between those priorities.
  • The day score is calculated against the full loaded workbook before EZDES chooses the requested number of jobs.
  • Non-h/h weights can receive a workload boost when more jobs of that weight are waiting, preventing a large heavier-weight backlog from being understated.
  • Speed, estimated time, and similar WO segments help break close scores and reduce unnecessary differences between nearby work.
  • The Priority value and placement explanation are internal planning aids; they are not printed on the finished schedule.
Jobs to plan, capacity, and schedule summary
  • Jobs to plan selects that many WO groups while retaining every spreadsheet line in those groups.
  • Fill available shift ignores the fixed job count and pulls work in priority order until the next item would exceed the available shift.
  • Available shift hours and shift start produce the planned-hours summary and on-screen estimated finish.
  • Unscheduled jobs shows how many available WO groups were not selected.
  • The on-screen times are estimates based on the current rules and sequence; they update after reordering.
Reordering, positions, pins, and history
  • In Schedule Positions, select one numbered position and then another to swap the two complete WO jobs.
  • Drag any Arranged data line. The green line shows the exact before-or-after insertion point, and the complete WO group moves together.
  • When a schedule row or numbered position has keyboard focus, Up Arrow and Down Arrow move that complete job.
  • Pin keeps a WO group at the top when the schedule is rebuilt.
  • Undo and Redo step through manual changes. Reset manual order returns to the calculated order.
  • The three schedule panels can be resized horizontally on a desktop by dragging their edges.
Search, completion dots, and job notes
  • Find TN or WO group filters the on-screen arranged table. Clear filter restores every scheduled line.
  • A green dot marks the final scheduled line belonging to a WO group.
  • Select the small note icon under internal priority to add or edit instructions for that WO group. A dot on the icon indicates a saved note.
  • The full note stays out of the on-screen data table. It prints as a wrapped line beneath that job’s first printed entry and is included in the exported Excel schedule.
Mixed weight layers
  • The Mixed weight layers panel follows the current arranged schedule and lists only scheduled lines whose two copper sides differ.
  • Clear means only copper is on the bottom and the layer remains eligible for normal similarity grouping.
  • Bottom image keeps that layer out of normal grouping and applies its targeted changeover rule when appropriate.
  • Unassigned leaves the layer without a manual bottom classification.
Schedule health and optional due-date urgency
  • The Schedule health cards summarize capacity use, weight changes, setup events, near-due jobs, and the scheduled weight mix.
  • Map a Due date column and enable Use due-date urgency to add a limited boost for overdue, today, two-day, and seven-day work.
  • Due-date urgency is optional and starts turned off, so the established production-day and copperweight priorities remain unchanged until a scheduler enables it.
  • Overdue rows receive a light red screen tint and jobs due within two days receive a light amber tint. These review colors are not printed.
  • Due-date details appear in the internal placement explanation and exported review data.
Planning insights
  • Planning insights records limited local signals from manual job moves and Bottom image assignments.
  • It can point out repeated patterns, but it never changes production rules or schedules automatically.
  • Clear local learning removes those observations from this browser without changing the workbook or saved schedule plan.
Print and Excel export
  • Print schedule produces a compact production view and omits internal priority, placement reasoning, scheduled-hours text, and expected completion times.
  • Job notes appear directly below the related entry and wrap across lines for readability.
  • Download arranged Excel exports the arranged rows plus schedule order, target speed, planned hours, notes, placement explanation, and priority for further review.
  • Filtering affects only the screen; printing restores all scheduled rows.
Saved information and troubleshooting
  • Presets, notes, pins, mixed-layer choices, manual order, and planning insights are stored locally in the current browser.
  • Using a different computer, browser profile, or file name can create a separate saved plan.
  • If Run schedule produces no result, confirm Copperweight and Speed mapping, check Data checks, and verify every used weight has a core-weight rule.
  • If the standalone HTML says Excel support did not load, reconnect to the internet and refresh so the workbook-reading library can load.
  • The local server is only required for selecting the newest workbook from a folder path; manual workbook upload does not require it.
